* How to configure the prompt to show only the working folder name with out full path?
```
# Add following statement to ~/.bashrc and run  source ~/.bashrc
export PS1='\[\e[1;35m\][WSL]\[\e[0m\] \[\e[1;36m\]\W\[\e[0m\] $ '
```
